# 🚀 100 Sites em 100 Dias

> **Um site por dia. 100 dias. 100 projetos. Uma evolução constante.**

Este repositório é o registro do meu desafio pessoal de desenvolver **1 site por dia durante 100 dias**, utilizando principalmente **HTML, CSS e JavaScript**.

A proposta é sair da teoria e colocar a mão no código todos os dias, criando projetos pequenos, explorando diferentes ideias, praticando UI/UX, melhorando minha lógica e desenvolvendo cada vez mais velocidade e qualidade no desenvolvimento frontend.

---

## 🎯 Sobre o desafio

O objetivo é desenvolver **100 projetos web em 100 dias consecutivos**.

Cada projeto deve ser desenvolvido de forma independente e representar algum tipo de aprendizado, experimento ou aplicação prática.

Durante o desafio, pretendo explorar:

* HTML5 semântico
* CSS3
* JavaScript
* Responsividade
* Flexbox
* CSS Grid
* Animações e transições
* Manipulação do DOM
* Eventos
* Formulários
* APIs
* LocalStorage
* Consumo de dados
* Componentização
* UI/UX
* Acessibilidade
* Performance
* Boas práticas de código
* Organização de projetos
* Design responsivo
* Interfaces inspiradas em aplicações reais

A ideia não é apenas criar **100 sites bonitos**, mas utilizar cada projeto como uma oportunidade para aprender alguma coisa nova.

---

## 📌 Regras

Para manter o desafio consistente, estabeleci algumas regras:

* [x] Criar 1 projeto por dia
* [x] Utilizar HTML, CSS e JavaScript como base
* [x] Cada projeto deve ter uma finalidade ou conceito próprio
* [x] Priorizar código escrito por mim
* [x] Tentar aprender algo novo em cada projeto
* [x] Manter os projetos organizados
* [x] Documentar os projetos
* [x] Publicar os projetos sempre que possível
* [ ] Completar os 100 dias
